# MobaXterm — Free Offline Installer

![Category](https://img.shields.io/badge/SSH_Client-blue?style=flat-square)

## About

MobaXterm is a free Windows terminal application combining an SSH client, X11 server, network tools, and a tabbed interface in one installer. Connect to remote Linux servers via SSH with X11 forwarding to display graphical Linux applications on Windows, use built-in FTP/SFTP browser, and run Bash commands in a local terminal using the included Unix toolbox. MobaXterm is a comprehensive remote computing toolkit for Windows developers and sysadmins.

## Common Problems & Limitations

- **Windows Only** — No macOS or Linux version needed (those platforms have native SSH)
- **Interface Complexity** — Feature-dense interface takes time to learn thoroughly
- **Commercial Home Edition** — Some features require paid Home Edition license
- **X11 Performance** — X11 forwarding over network adds latency for GUI applications
